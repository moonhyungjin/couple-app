# 🏡 우리 둘만의 집 · 부부 전용 앱 MVP (`D:\Project\couple-app`)

출시 목적이 아닌 **남편(Android) + 아내(iPhone)** 두 사람만 오붓하게 쓰는 **모바일 웹앱(PWA) MVP**입니다.
애플 개발자 계정(연 14만 원)이나 앱스토어 심사 없이, 두 사람의 스마트폰 홈 화면에 네이티브 앱처럼 설치해 무료로 영구 사용할 수 있습니다.

---

## ✨ 포함된 5대 핵심 기능 (하단 5탭)

1. **`🏠 홈·문답` 탭**
   - **결혼기념일 / D+N 카운터 & 다음 주년 안내** (우측 상단 `⚙️` 버튼으로 부부 애칭·기념일 수정 가능)
   - **실시간 상태 스탬프 & 한마디**: `출근길 🚇`, `열일중 💻`, `칼퇴예정 🏃`, `배고파 🍖`, `보고싶어 💛` 등 원터치 변경 + **`💌 배우자 콕 찌르기`** 호출 배너
   - **오늘의 부부 블라인드 문답**: 남편과 아내가 **둘 다 답변을 등록해야만** 상대방의 대답이 잠금 해제되는 데일리 질문 카드
2. **`🛒 장보기·할일` 탭**
   - `장보기 🥬` / `집안일 🧹` / `챙길것 📌` 카테고리별 실시간 체크리스트 및 담당자(`함께` / `남편` / `아내`) 배지
3. **`🎟️ 소환 쿠폰` 탭**
   - `어깨·다리 안마 20분권`, `설거지 1회 완전 면제권`, `주말 아침 늦잠 보장권`, `야식 무조건 쏘기권` 등 쿠폰 발행·충전·사용 시 상단 호출 알림 발송
4. **`🍽️ 오늘 뭐먹지` 탭**
   - 우리 집 단골 메뉴판(`집밥` / `배달·외식` / `야식·안주`) + **`🎲 랜덤 메뉴 뽑기` 룰렛 애니메이션** + **`📣 오늘 저녁 이걸로 콜!`** 호출 기능
5. **`🗺️ 추억지도·도감` 탭**
   - **우리 둘만의 포토 추억 지도 (Leaflet + OpenStreetMap 무료 연동)**:
     - 우리가 찍은 사진이 지도 위에 **폴라로이드 썸네일 마커**(`🤖`/`🍎` 배지 포함)로 바로 표시됩니다.
     - **3가지 자동·수동 위치 지정 방식**:
       1. **📷 사진 EXIF GPS 자동 인식**: 스마트폰으로 찍은 사진에 위치 정보(EXIF)가 들어 있으면 사진만 골라도 찍은 장소의 위도·경도와 촬영 날짜, 동네 이름을 자동으로 잡아줍니다.
       2. **📍 내 위치 버튼**: 지금 데이트 중인 현장에서 바로 찍어 올릴 때 현재 GPS 위치로 즉시 이동합니다.
       3. **🔍 장소 검색 & 👆 지도 터치**: 사진에 GPS가 없거나 옛날 사진을 올릴 때도 지명 검색(예: `성수동`, `광안리`)이나 지도 터치 한 번으로 원하는 자리에 사진 핀을 꽂을 수 있습니다.
   - **배우자 취향 도감 (컨닝페이퍼)**: 아내·남편의 최애 카페 주문법, 옷·신발·반지 사이즈, 음식 호불호, 선물 위시리스트 기록

## 계정별 로그인 설정

앱에서 각자 이메일·비밀번호로 회원가입합니다. 한 사람이 공간 이름과 자기 역할을 선택해 부부 공간을 만들고, 배우자가 초대 코드를 수락합니다. 배우자의 역할은 반대로 정해집니다. 사진·애칭은 본인만 수정하고, 기념일 등 공유 정보는 함께 수정합니다.

1. Supabase Authentication에서 이메일 회원가입과 이메일 인증을 활성화하고, Site URL을 실제 배포 주소로 설정합니다. 사용자는 앱의 **회원가입**에서 가입하고 이메일 인증 링크를 누른 뒤 로그인합니다. 관리자에서 계정을 만들 필요가 없습니다. 인증이 꺼진 개발 환경에서는 가입 직후 바로 진행합니다.
2. Vercel 서버 환경변수에 `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `SUPABASE_ANON_KEY`(또는 `SUPABASE_PUBLISHABLE_KEY`)를 설정합니다. 공개 Auth 키는 가입 요청에 사용하고 service role 키는 저장소·멤버십 API에서 사용합니다. 키는 브라우저에 전달하지 않습니다. `COUPLE_HUSBAND_USER_ID`, `COUPLE_WIFE_USER_ID` 설정은 더 이상 사용하지 않습니다.
3. 기존 테이블이 있다면 다음 SQL을 실행하여 익명 키로 API를 우회하지 못하게 합니다. Storage의 `couple-app-state`, `couple-app-photos` 버킷도 비공개로 유지하고, anon/authenticated에 직접 접근을 허용하는 기존 Storage 정책을 제거합니다. 서버는 service role로 접근합니다.

```sql
alter table public.couple_room enable row level security;
revoke all on public.couple_room from anon, authenticated;
```

4. [supabase-spaces.sql](./supabase-spaces.sql)을 Supabase SQL Editor 또는 Vercel Storage의 Query에서 실행합니다. Vercel Query에서는 **Read-only를 끄고**, 파일 전체(`DO $migration$` 블록 포함)를 한 번에 실행합니다. 공간·멤버십 테이블과 서버 전용 함수를 만듭니다. 이전 `supabase-pairing.sql`은 실행하지 않아도 됩니다. 이미 실행했던 이전 테이블과 데이터는 보존됩니다.
5. 환경변수 설정 후 배포합니다. 한 사람이 **회원가입 → 이메일 인증 → 로그인 → 공간 만들고 배우자 초대하기**를 진행합니다. 배우자는 **회원가입 → 이메일 인증 → 로그인 → 배우자로 연결하기**에서 받은 코드를 입력합니다. 코드는 15분 동안 한 번 사용할 수 있으며 본인이 만든 코드는 본인이 수락할 수 없습니다. 새 코드를 만들면 이전 코드는 무효가 됩니다.
6. 연결 전에는 `/api/state`와 `/api/photo`가 거부되는지 확인합니다. 연결 후에는 내 사진만 바꿀 수 있고 배우자 사진은 눌러 확대할 수 있어야 합니다. 내 사진은 72px, 배우자 사진은 92px로 표시하며 애칭도 본인 것만 수정합니다.

한 계정은 한 공간에만 가입하고 한 공간에는 두 명만 참여합니다. 초대 수락과 가입을 DB 트랜잭션으로 처리하여 동시에 수락하더라도 중복 가입을 막습니다. 초대 코드는 두 계정이 서로 배우자로 연결하는 데 동의했음을 확인하는 절차입니다. 생성한 역할은 다른 사용자의 요청이나 화면 전환으로 바뀌지 않습니다.

공유 상태와 프로필은 `couple-app-state/spaces/<공간 UUID>/`에, 사진은 `couple-app-photos/spaces/<공간 UUID>/`에 저장합니다. API는 요청 본문이 아닌 서버에서 확인한 멤버십으로 공간을 결정합니다. 설정이 누락되면 API 접근이 차단됩니다. 세션은 HttpOnly 쿠키에 저장하고 만료 시 갱신합니다. 비밀번호 분실 시 Supabase 관리자에서 계정을 복구합니다.

### 이전 공용 기록 가져오기

기존 루트의 `state.json`, 프로필, 사진 및 이전 `couple_room` 행은 삭제하지 않습니다. 첫 가입자에게 임의로 할당하지 않으며, 관리자가 본인 부부의 공간임을 확인한 뒤 가져옵니다. 먼저 공간을 만들고 배우자가 참여하기 **전**, Supabase 테이블에서 공간 UUID와 소유자 UUID를 확인한 뒤 서버 환경변수가 설정된 터미널에서 실행합니다:

```powershell
node scripts/import-legacy.cjs <공간-UUID> <공간-소유자-UUID>
```

원본을 보존하고 참조된 사진과 프로필을 해당 공간으로 복사합니다. 이미 다른 기록이 있는 공간에는 덮어쓰지 않습니다. 이후 배우자가 초대를 수락하면 기존 기록으로 시작합니다. 계정·공간이 바뀌면 브라우저의 이전 캐시도 새 공간에 업로드하지 않습니다. 계정 정보 없이 남아 있던 로컬 기록은 `couple_app_legacy_backup_v1`에 백업합니다.

## 로컬 실행

로컬 서버도 같은 인증·클라우드 API를 사용합니다. 위 환경변수를 로컬 프로세스에도 설정한 뒤 실행합니다. 파일 더블클릭과 인증 없는 로컬 파일 저장 모드는 더 이상 지원하지 않습니다. 기존 `data/` 파일은 삭제하지 않으며 자동 업로드하지 않습니다.

```powershell
cd D:\Project\couple-app
node server.cjs
```

`http://localhost:4173`에서 확인합니다. 실제 휴대폰 사용은 HTTPS로 배포한 주소를 사용합니다. 두 기기는 클라우드를 주기적으로 조회해 동기화합니다.

검증: `node --test tests/*.test.cjs` (API 저장소를 모의한 가입·권한·공간 격리 테스트, 가입 화면 동작, 양쪽 역할의 프로필 렌더링 테스트). 실제 Supabase SQL 실행과 두 휴대폰의 가입·이메일 인증·연결 확인은 배포 환경에서 별도로 진행합니다.

## 📱 스마트폰 홈 화면에 진짜 앱처럼 설치하는 법 (PWA)

1. **남편 (Android - Chrome)**
   - 주소 접속 → 우측 상단 메뉴(`⋮`) → **`홈 화면에 추가` (또는 `앱 설치`)**
2. **아내 (iPhone - Safari)**
   - 사파리로 주소 접속 → 하단 가운데 **`공유` 버튼 (`↑`)** → 아래로 스크롤하여 **`홈 화면에 추가`** 터치
   - 바탕화면에 **우리둘집** 아이콘이 생기며, 실행 시 주소창 없이 일반 아이폰 앱처럼 전체 화면으로 작동합니다.
